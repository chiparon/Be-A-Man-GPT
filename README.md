# Be-A-Man-GPT

让 GPT 从"和事老"变成一个有主见、敢拍板、敢认错的同事。

## 问题

GPT 的典型毛病：

- 用分析代替判断："各有优劣，取决于需求"
- 为现状找补："当时的选择也有其合理性"
- 顺从：你说什么都对，该反驳时不反驳
- 废话：复述问题、评价问题、结尾总结，有用的信息只占三成

## 文件

- [custom-instructions.md](custom-instructions.md)：v1，通用版自定义指令
- [spells/](spells/)：针对废话、无决断、过度设计三个维度的三种写法
  - [A-rules.md](spells/A-rules.md)：规则型，明确的禁令和必须项
  - [B-persona.md](spells/B-persona.md)：人设型，描述一个有品味的资深工程师
  - [C-examples.md](spells/C-examples.md)：示范型，"不要这样 / 要这样"的对照样例
- [tests.md](tests.md)：12 道测试题和评分标准，按维度统计分数

每次只贴一个版本，跑完测试再换下一个，这样才能比出哪种策略对 GPT 最管用。

## 用法

1. 打开 ChatGPT → 设置 → 个性化 → 自定义指令，把 `custom-instructions.md` 里的指令贴进去。
2. 新开对话，逐题跑 `tests.md`，按标准打分。
3. 改指令，再跑一遍，对比分数。

## 注意

- 提示词只能把模型往前推一段。保守是训练出来的，对话一长就会慢慢回退，所以要定期复测。
- 防止矫枉过正。"有主见"不是"为反对而反对"，也不是"死不认错"。测试题里有专门检查这一点的题目。
